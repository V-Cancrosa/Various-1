# Various

Assorted Foundry VTT and Roll20 tools, one folder each.

| Folder | What it is | Install |
|---|---|---|
| [`map-scene-browser`](map-scene-browser) | Foundry v14 module: a GM browser for map and scene modules listed in a CSV, with search, type filter, Install and Uninstall | `https://raw.githubusercontent.com/V-Cancrosa/Various-1/main/map-scene-browser/module.json` |
| [`roll20-wfrp2e`](roll20-wfrp2e) | Roll20 character sheet for Warhammer Fantasy Roleplay 2e (Polish): stats, skills, weapons with hit locations and Ulric's Fury, spells with Tzeentch's Curse | Paste `sheet.html` and `sheet.css` into *Game Settings → Custom* (Pro), Legacy Sanitization off |
